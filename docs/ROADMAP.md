# Product roadmap

Comment Studio is designed for editors who need realistic social comment overlays without interrupting their workflow.

## Near term

- Move the deployed application source into this repository.
- Document local development and deployment.
- Add CI for type checking and production builds.
- Add export presets for 16:9, 9:16, and 1:1 compositions.

## Product direction

- More platform layouts while keeping the core controls consistent.
- Reusable custom comment and identity presets.
- Better accessibility, keyboard navigation, and screen-reader labels.
- Small, focused visual regression coverage for platform comment cards and exports.
