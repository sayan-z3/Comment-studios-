# Contributing to Comment Studio

Thanks for helping make Comment Studio more useful for video editors.

## Before opening a change

- Check existing issues and pull requests first.
- Keep the experience free of login, payment, and unnecessary account requirements.
- Preserve the editor-first workflow: configure a comment, preview it, and export it quickly.
- Avoid copying protected platform assets or implying an official relationship with a social network.
- Keep generated content clearly fictional and suitable for creative mockups.

## Recommended pull request format

Please include:

1. A short summary of the user problem.
2. What changed and why.
3. Screenshots or a short screen recording for visual changes.
4. Manual verification steps.
5. Any follow-up work or known limitations.

## Visual design guidelines

- Prefer clear hierarchy over dense panels.
- Keep controls readable on small screens.
- Use platform-specific styling only where it improves recognition.
- Make the primary export action obvious.
- Preserve keyboard focus states and sufficient color contrast.
- Avoid adding decorative motion that competes with the live preview.

## Commit style

Use a short, imperative subject line, for example:

- `feat: add TikTok comment layout`
- `fix: preserve transparent export backdrop`
- `docs: clarify local setup`
- `refactor: simplify preset filtering`

## Reporting a security issue

Please do not open a public issue for a suspected security vulnerability. Follow the instructions in [SECURITY.md](SECURITY.md).
